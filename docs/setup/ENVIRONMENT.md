# YUL Environment Setup

## Configuration Files
1. Copy `.env.template` to `.env`
2. Copy `config/templates/bitcoin.conf.template` to `config/bitcoin.conf`
3. Update configuration values in `.env`

## Required Environment Variables
- YUL_RPC_USER: RPC username for node access
- YUL_RPC_PASSWORD: RPC password for node access
- YUL_NODE_HOST: Node hostname (default: node1)
- YUL_NODE_PORT: Node RPC port (default: 8332)
